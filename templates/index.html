¿Cómo autenticarse con gcloud?
Instalar Google Cloud CLI → descargar
Inicializar (una sola vez)
gcloud init Te pedirá iniciar sesión y seleccionar proyecto.
Generar credenciales ADC para Python
gcloud auth application-default login Abre el navegador para iniciar sesión. Crea el archivo:
%APPDATA%\gcloud\application_default_credentials.json
Después de esto, el panel mostrará ✓ ADC configurado y ya no necesitas JSON ni env vars.
gcloud auth login y gcloud auth application-default login son comandos distintos — los dos son necesarios.
